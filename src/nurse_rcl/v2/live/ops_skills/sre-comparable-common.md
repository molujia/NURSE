# 同类证据与有界解释

先解释上一实际回执回答了什么、还缺什么，再自主选择下一问题或停止；不按固定路线打卡。所有候选可达，未读目录不意味着必须读完。

mechanisms 的 compare_candidates 按机制 key、definition、窗口、正式或补充类别配对。相同字段不构成区分证据，不用一个候选的某机制与另一个候选的不同机制解释领先。多来源保留身份，缺一侧表示未发布，不填正常。

scoring 给正式分项和真实选择链。只有实际交付的细节可引用，后台留存不是已读；池内胜出、家族代表与所选家族进入聚合不同。接受、症状支持、根因角色和因果确认不同，不能从未知数量、accepted 或排名倒推贡献。

报告先总结再逐步汇报。step_findings 以真实 s1 等步骤为键，不重复 step_ref，不给某步发现可以省略；不能把综合挂到未交付该证据的步骤。只读建议先明确 verification_question；无可靠条件结果时 possible_outcomes=[]、outcome_subject_ref=null。有分支必须一个实际条件或谓词，不拼接多个谓词，也不借单条件推断正式分数变化。
