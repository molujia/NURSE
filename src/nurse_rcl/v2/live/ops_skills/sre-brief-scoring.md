# 正式评分解释

问题：正式排序的已有分项与竞争机制如何相互制约？inspect_candidate focus="scoring" 或 compare_candidates(left_candidate_service_key, right_candidate_service_key, focus="scoring", cursor) 读取原发布值；两个候选必须不同。
反馈：未发布明确未发布；只部分发布不推断全案首位。分数不是概率，哈希破平不是证据。依据正式分项解释，但不能重排或让补查回写；单候选分数不能推出“唯一”“全部”跨集合结论。
停止：正式结论和保留意见能诚实报告即可，不为复述数值追加无意义动作；未处理竞争问题明确列为未查。
