# 案例边界

检查价值：能缩小不确定性即可，不要求一次决定唯一根因；先指出一个具体区分问题，再依据已返回结果选择定向工具、继续浏览、有理由重读或停止。不因目录尚未读完就反复重开已有窗口问题，不强制候选对或固定流程。

问题：现在调查什么窗口、哪些服务，哪些观测可用？
前提：只认准入快照和能力索引，不从案例名猜故障。已有合法ID可直接检查，不必先找目录。
工具：inspect_case 按候选返回有界概览，不分页遍历全案证据流；inspect_candidate 定向展开；browse_index 找未显示候选；read_node 展开注册卡片。cursor 初次为null，续页必须原样复制同范围游标。
状态：候选未读、完整记录未展开、观测未测／不可用、判断false／unknown是四种状态。全案窗口已给出时，不要把候选目录尚未看完叫作窗口未知。机制计数不是支持票数，摘要发放的原卡片ID仅可作为展开入口，不等于已读取完整条件。
分页：cursor=null 是重读首页；has_more=true 时，未展开记录仍存在，要继续同范围查询应复制 next_cursor 并保持其他参数不变。首页范围和候选总数不能混淆，不能由首页未显示宣称不存在。
回应：候选目录可能成功但 visible_card_ids 为空；用 action_index 配空 card_ids 回应。receipt_card_id 不是自动获得的证据权限，只有列在同一动作的 visible_card_ids 才能作为回应卡片。
支持：已有观测可形成待核验问题，选择症状、依赖或竞争候选的检查。
反证：窗口或覆盖不支持原先假设时，修改公开判断，不选择性删除不利项。
未知：缺模态、未展开、未发布各自记录，均不代表健康。概览不是完整机制判断。
停止：无可区分的合法检查就明确未知停止，不要求耗尽预算；不能以八次动作走完所有候选。
只编排补充调查，不声称调度了正式内核。所有调用含续页与拒绝都消耗一个动作。
反馈选路：先简述上一步新增或未新增什么、还需区分哪个问题，再参考 investigation_routes 自主选择。该表只给合法入口，不是价值排序；可查其他目录和非首位候选。execution_history、core_reusable、new_publication 是独立维度，不把重复或复用当新证据。允许有理由重读或停止，不强制切换或耗尽预算。prior_response_target 只提示上一真实动作及合法引用，responds_to 仍须自主选择；停止不证明数据穷尽。
