# 症状与测量

检查价值：能缩小不确定性即可，不要求一次决定唯一根因；先指出一个具体区分问题，再依据已返回结果选择定向工具、继续浏览、有理由重读或停止。不因目录尚未读完就反复重开已有窗口问题，不强制候选对或固定流程。

问题：这个服务表现为持续异常、短峰，还是仅有摘要变化？竞争候选是否也有症状？
前提：复制准入candidate_service_key；测量复制已绑定request_key，不给路径、阈值或自己猜的数值。
工具：inspect_candidate 看现有摘要和证据；compare_candidates 对照两个不同候选；measure_signal 显式测一个已注册序列或复用核心同一测量；read_node 看完整结果。
分页：cursor=null 重读首页；要检查该候选未展开内容，用原 next_cursor 续页且不改其他参数。没有新发布或新的区分问题时，重复同一首页不能解决“还有什么证据”。可按反馈续页、定向查关联记录、检查其他合法候选或停止，不强制切换对象。
支持：依据实际episodes和谓词继续核验相关机制；摘要本身不能证明异常段。
反证：verified_normal、方向相反或不满足必要条件应削弱当前解释，转查另一机制或候选。
范围：单条信号 false／unknown 只约束该信号及窗口，不等于服务正常或已排除；verified_normal=false 也不直接证明异常。保留竞争解释，下一步优先回答具体未决问题。
未知：覆盖不足、未测、缺少所需信号如实保留，可用next_checks选择有区分价值的一项。
停止：现有数据不能区分或重复测量没有新增价值时停止。复用不等于独立的第二份支持，补查不进入正式评分。
反馈选路：先简述上一步新增或未新增什么、还需区分哪个问题，再参考 investigation_routes 自主选择。该表只给合法入口，不是价值排序；可查其他目录和非首位候选。execution_history、core_reusable、new_publication 是独立维度，不把重复或复用当新证据。允许有理由重读或停止，不强制切换或耗尽预算。prior_response_target 只提示上一真实动作及合法引用，responds_to 仍须自主选择；停止不证明数据穷尽。
